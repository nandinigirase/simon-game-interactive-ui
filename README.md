# 🎮 Simon Game Interactive UI

An interactive **Simon Game** built with **HTML, CSS, and JavaScript**, featuring modern design, smooth animations, and enhanced gameplay functionality. This project recreates the classic memory challenge with a fresh, responsive interface and extra features for a more engaging experience.

## ✨ Features
- **Interactive CSS Styling**
  - Vibrant color buttons with glow effects
  - Smooth transitions and responsive layout
  - Dark mode toggle for accessibility

- **Core Gameplay**
  - Random sequence generation that grows each round
  - Player input validation with instant feedback
  - Score tracking and round indicator
  - Start, Restart, and Strict Mode options

- **Enhanced Functionality**
  - Sound effects for each button press
  - Difficulty levels (Easy, Medium, Hard)
  - Animated feedback on mistakes (shake/flash)
  - High‑score storage using localStorage

## 📂 Project Structure
- `index.html` → Game layout
- `style.css` → Interactive styling and animations
- `script.js` → Game logic and functionality
- `assets/` → Sounds, icons, and visuals
